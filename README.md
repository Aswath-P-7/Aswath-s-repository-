A sustainable bicycle-sharing solution designed to improve campus mobility for students without personal transportation. This project leverages smart technology to provide an efficient, secure, and eco-friendly commuting experience within campus environments.

📱 Features
Android Application for easy bicycle booking
Real-time GPS Tracking for locating and monitoring bicycles
Smart Lock System using ESP32 and solenoid lock for secure access
Seamless Payment Integration for quick and hassle-free transactions
User-friendly Interface for smooth navigation and usage
⚙️ Technologies Used
Android (Java/Kotlin)
ESP32 Microcontroller
GPS Module
Solenoid Lock Mechanism
Payment Gateway Integration
🌱 Objective

To promote a greener and healthier campus lifestyle by reducing dependency on motorized transport while ensuring convenience and accessibility for students.

🚀 Impact
Enhances mobility within campus
Reduces carbon footprint
Encourages sustainable transportation habits
Provides a cost-effective commuting solution
